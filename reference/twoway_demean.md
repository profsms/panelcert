# Two-way within transformation by alternating projections (unbalanced-safe)

Two-way within transformation by alternating projections
(unbalanced-safe)

## Usage

``` r
twoway_demean(x, unit, time, tol = 1e-10, maxit = 10000L)
```

## Arguments

- x:

  numeric vector to demean

- unit, time:

  raw identifier vectors (any type)

- tol, maxit:

  convergence controls

## Value

the two-way-demeaned numeric vector \`M x\`
